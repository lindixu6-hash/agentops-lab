# Contributing

Thanks for helping improve Awesome Agentic Engineering.

This repo values practical, source-backed, production-oriented material. Prefer real patterns, concrete templates, and failure cases over vague opinions.

## Good Contributions

- A real agent failure mode and how you detected it
- A repeatable eval scenario
- A useful launch checklist item
- A security or permission boundary pattern
- A cost control pattern
- A short case study with architecture, tradeoffs, and result
- A template other teams can reuse

## Contribution Format

For a failure case, use:

```text
Title:
Context:
What failed:
Why it failed:
Impact:
Detection signal:
Fix:
Prevention:
```

For a pattern, use:

```text
Title:
Problem:
Use when:
Avoid when:
Implementation notes:
Tradeoffs:
Example:
```

For a tool or resource, include:

```text
Name:
URL:
Category:
Why it matters:
Limitations:
```

## Quality Bar

Please avoid:

- Hype without concrete examples
- Unsourced benchmarks
- Paid promotions
- Affiliate links
- Star-for-star or engagement exchange requests
- Unsafe automation patterns

## Review Principles

Maintainers should ask:

- Is this useful to someone shipping an agent?
- Can a reader apply it within one hour?
- Does it make risks, tradeoffs, or assumptions visible?
- Is it specific enough to test or review?
