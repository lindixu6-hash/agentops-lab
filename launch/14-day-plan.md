# 14-Day Launch Plan

This plan is designed for an open-source repository that earns real stars by being useful, collectible, and easy to share.

## Day 1: Repository Launch

Ship:

- README
- Chinese README
- Agent Card template
- Eval Plan template
- Launch Checklist
- Contribution guide

Post angle:

```text
Most AI agent demos fail in production for boring reasons: tool permissions, memory drift, missing evals, hidden costs, prompt injection, and unclear recovery.

I made a practical open-source playbook for shipping agents that survive real users.
```

## Day 2: Chinese Developer Communities

Post to:

- V2EX
- 掘金
- 知乎
- 即刻
- 微信技术群

Use a Chinese title:

```text
我整理了一份 AI Agent 生产就绪清单：模板、评估、失败模式和上线检查
```

## Day 3: English Developer Communities

Post to:

- Hacker News
- Reddit
- X
- LinkedIn
- Relevant Discord or Slack communities

Use an English title:

```text
Awesome Agentic Engineering: templates, evals, and failure modes for production AI agents
```

## Day 4: Add Failure Cases

Add at least five:

- Silent failure
- Tool abuse
- Memory drift
- Prompt injection
- Cost explosion

Each case should include:

- Context
- What failed
- Detection signal
- Fix
- Prevention

## Day 5: Make A Shareable Scorecard

Create one image:

```text
Is your AI agent production ready?
10 checks before real users touch it.
```

Include the 10 scorecard rows from the README.

## Day 7: Publish The First Article

Title options:

- Why Most AI Agent Demos Never Reach Production
- The Boring Engineering Work Behind Reliable AI Agents
- AI Agents Need Evals Before Autonomy

Article structure:

- Hook: demos are easy, operations are hard
- Five failure modes
- The scorecard
- Link to repo

## Day 10: Invite Contributors

Message 20 builders who have shipped LLM apps or agents.

Short message:

```text
I am collecting real-world AI agent failure modes and production patterns here: https://github.com/lindixu6-hash/awesome-agentic-engineering

If you have a painful lesson from building agents, I would love to include it with attribution.
```

## Day 14: Second Launch

Ship:

- New failure cases
- Contributor section
- Roadmap
- First case study
- Issue labels for help wanted and good first issue

Post angle:

```text
Two weeks ago I launched a production-readiness checklist for AI agents.

The community added new failure modes around memory, tools, cost, and security. Here is the updated version.
```

## Rules

Do:

- Ask for feedback
- Ask for real failure stories
- Ask people to contribute cases
- Share useful excerpts
- Track stars, forks, issues, and referrers daily

Do not:

- Buy stars
- Trade stars
- Offer rewards for stars
- Spam issues or discussions
- Pretend the project is larger than it is
