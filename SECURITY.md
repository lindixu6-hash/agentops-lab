# Security Policy

This repository documents patterns for production AI agents. Please report security issues if you find:

- Unsafe examples that encourage secret exposure
- Tool permission patterns that could cause unauthorized writes
- Prompt injection examples that accidentally disclose private material
- Vulnerable code in the scorecard CLI

## Reporting

Open a private security advisory if the repository is hosted on GitHub, or contact the maintainers through the profile listed in the repository.

Please do not publish exploitable details before maintainers have a chance to respond.
