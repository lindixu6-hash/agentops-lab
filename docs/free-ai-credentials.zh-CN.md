# 免费 AI 证书策略

> 核验日期：2026-08-17

## AI-901 是否免费

不是常态免费。

微软官方 Azure AI Fundamentals 页面当前对中国地区显示 **50 美元**，价格会根据考试所在国家或地区变化。第三方中国报名渠道显示的价格可能更高，不建议在未核验官方结算页前购买。

- 官方认证页：https://learn.microsoft.com/zh-cn/credentials/certifications/azure-ai-fundamentals/
- AI-901 考试页：https://learn.microsoft.com/zh-cn/credentials/certifications/exams/ai-901/

免费的是：

- Microsoft Learn 自学路径；
- AI-901 Practice Assessment；
- Exam Sandbox；
- 部分 Microsoft Applied Skills 实验型凭证。

偶尔会有 Microsoft Skills Fest、Virtual Training Day、学校 MSLE 项目或合作伙伴活动提供免费 / 折扣 Voucher，但没有长期有效、人人可领的 AI-901 免费券。只有结算页显示应付 **0** 才能视为免费。

## 当前免费优先项

### Microsoft Applied Skills：Generate reports with AI research agents

- 官方微软凭证；
- 学习路径约 1 小时 12 分；
- 45 分钟交互式实验考核；
- 面向业务用户，贴合 AI 产品 / 运营的研究与报告场景；
- 当前官方页面仍提供 `Take Assessment`。

官方页面：

https://learn.microsoft.com/en-us/credentials/applied-skills/generate-reports-with-ai-research-agents/

注意：实验界面为英文；启动后 72 小时内不能再次启动，所以应先完成学习路径再进入考核。

## 本项目的取舍

1. 不支付 AI-901 考试费；
2. 先完成 AgentOps Lab 和比赛提交；
3. 空余时间完成免费的 Microsoft Applied Skills；
4. 持续关注微软官方 Voucher 活动；
5. 只有拿到 100% Voucher 时才报 AI-901。

简历中应写真实凭证全名，不能把 Applied Skills 写成 Azure AI Fundamentals Certification。
