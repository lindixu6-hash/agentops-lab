# Code of Conduct

This project aims to be practical, specific, and respectful.

Expected behavior:

- Share concrete examples and tradeoffs.
- Critique ideas without attacking people.
- Credit original sources and maintainers.
- Avoid spam, self-promotion without context, and engagement manipulation.

Unacceptable behavior:

- Harassment or discriminatory language.
- Posting secrets, private data, or unsafe instructions.
- Star-for-star, paid star, or fake engagement requests.
- Repeated low-effort promotion.

Maintainers may remove content that makes the project less useful or less safe for contributors.
